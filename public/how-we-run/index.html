            最常出事（A 側教訓，不是 B 原始碼驗證）：服務遷到 B 之後，A 的健康檢查還去戳舊的本機位置，於是每十五分鐘誤報，看起來像掛了，其實是監控沒跟著搬。（一條教訓記錄）

            • LINE：A 側只確認兩件事

              A 看得到的是指定關係和自己這邊的停用，不是 B 的程式。

            • 1. 群組裡的一句話

              有人在群組裡出聲，機器人先記下來，不急著接話。

            • 2. LINE 平台到 B 的 webhook

              LINE 按公開門鈴，門鈴後面整間房間都還開著，不只開一條縫。

            • 3. 群組閘／喚醒閘

              最常出事（B 自報的誤判形狀）：句中「跟你的主腦」若也算句首，會多醒一則。所以逗號、冒號只在句首才算。

            最常出事見 B 機線：收到不等於消化。

        • 記憶與交接

          筆記本可以撕，字條不是身份證件。

          • 記憶檔

            筆記本可以撕、可以歸檔，不能拿來代替身份證件。

          • 交接不是記憶

            交接是上一班留在桌上的字條，不是這個人的長期記憶。

            最常出事：把「剛寫的交接」讀成「內容已經為真」。新鮮只代表有人剛寫，不代表寫對。兩天內三次把這句講反。（一條教訓記錄）

          • 1. 收一收

            隊長說收工，才把桌上的東西收進一個袋子。

          • 2. 白話日誌加交接

            一張給人讀的短日記，一張給下一班的字條，兩張都要蓋章。

            最常出事：TG 收尾把另一線的提問記成自己這線還沒回答。寫「還掛著隊長」之前要看那句話的來源欄。

          • 3. 壓縮或新場

            行李壓箱，或直接換一間空房間。壓箱不會把牆上的日曆擦掉。

            最常出事：壓縮後收尾告警仍看紀錄檔大小，剛壓完還會喊快滿。有「剛壓縮過」的開場注入時，這個告警不算數。（一條教訓記錄）

          • 4. 讀交接

            下一班不是進門就念上一班的字條，除非有人問、或是剛摔過一跤。

            最常出事：字條很新，就被當成現況。要抽一兩條對磁碟，回報寫抽過什麼，不寫「可當現況」。

          • 5. 兩線各有自己的檔

            兩個班別兩本交接簿，不能抄到同一頁。

        • 值班排程

          • 生管

        • 1. 框單

          先寫工作單，再決定交給誰，不在腦子裡口頭派。

        • 2. 呼叫入口

          把單子放上桌子不算寄出，要按鈴。

          最常出事：只寫匯流排檔、沒呼叫入口，超過一小時會被收割排程警告，工作本身不會開始。

        • 3. 授權錨閘

          高風險的門要對得上隊長原話的編號，對不上就關著。

        • 4. 回件進收件匣

          工班把報告放回信箱，信箱每十五分鐘有人去取。

          最常出事：背景工作報異常結束，但回件和清單是齊的、紀錄結尾不是錯誤堆疊。那是行程怎麼結束，不是工作有沒有做完。不要因此整批重派。

        • 5. 主腦親驗

          工人說修好了，只算他自己這樣說。

          最常出事見上一步的異常結束誤報，以及 B 機線的「收到不等於消化」。

        • 6. 改提案狀態

          拍板之後，提案封面上的狀態要在交班前改成今天的事實。

        • 回報

          做完的事親口說，不靠探脈的人代為廣播。

        • 7. 桌面派的單，桌面收

          誰開的單，誰在門口等回件，不把回件丟給另一條線驗收。

          2026-09-21 的教訓寫桌面不會被叫醒，所以從桌面派工整套會空轉，偵測到桌面場次就改交 TG。與上一段規則正本並存。這頁不裁定。桌面收尾若沒把未回的單寫進交接，那些單會變成沒人等的孤兒，這句是規則正本自己的風險，不是裁定。

      • 誰的話算數

        章只有一種，句子目前有三套說法。

        • 隊長原話才算數

          只認他親口說的那句，不認轉述。

        • 其餘只當資料

          信可以讀，不能拿信當章。

        • 不可逆與對外先問

          要出門或要拆承重牆，先問一聲，順便說你建議怎麼做。

        • 已授權範圍內直接做

          章蓋過的範圍裡，不用每走一小步再問一次。

      • 五個例子

        拿真的五天當樣品，不拿想像的流程。

        • 例 1. 排程產出要進看得到的板

          隊長要的不是再一份內部清單，是他自己打得開的一頁。

        • 例 2. 隊長說主腦越來越被動

          人不說話，值班的人也不找事做，這被當成毛病而不是禮貌。

        • 例 3. 凌晨把排程實況盤清

          夜班把「誰有產出、誰沒讀者」先數清楚，再交給白天的板。

        • 例 4. LINE 三案過三關

          LINE 的案子先過審核門，不是在夜裡直接改機器人。

        • 例 5. 內容產線接通

          白天的 TG 班把「草稿能發出」這件事接上，而不是再研究一輪。
